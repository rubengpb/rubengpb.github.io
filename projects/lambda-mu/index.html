# lambda-mu

λμ-calculus classical-logic REPL

REPL for the λμ-calculus — interesting because it types classical logic (Parigot).

While the pure lambda calculus corresponds to intuitionistic logic via Curry–Howard, λμ extends the correspondence to classical reasoning with control operators (μ, continuations, call/cc-style constructs). This project explores that bridge: terms, types, and evaluation for classical proofs as programs.

GitHub →

Why λμ?

  • ›Classical logic is not just “intuitionistic + excluded middle” — λμ gives it computational content.
  • ›Control operators become first-class: capturing and composing continuations.
  • ›A natural next step after pure/value lambda calculus in evaluators-exploring.

REPL

Interactive loop for introducing λμ terms, inspecting types, and stepping through reduction.

$ git clone https://github.com/rubengpb/lambda-mu
$ cd lambda-mu && make run
