# evaluators-exploring MSc thesis · REPL

lambda-calculus pure value evaluators teaching research

REPL for the pure and value lambda calculus, designed primarily for teaching and research. It gathers a broad range of evaluation strategies and evaluator implementation techniques in one place. Part of my MSc thesis (TFM).

GitHub → Try online (λ-REPL)

Goals

Make operational semantics concrete. Instead of describing strategies on paper, run them: normal order, applicative order, call-by-value / call-by-name, and variations, with different evaluator styles (naïve substitution, environments, closures, etc.).

  • ›Compare strategies side-by-side on the same terms.
  • ›Show how implementation technique affects behaviour and efficiency.
  • ›Provide a playground for courses and for exploring confluence and termination.

Implementation notes

Core is a small, focused codebase: lexer, parser, AST, evaluator variants and pretty-printer.

evaluators-exploring/
├── src/        — evaluators, strategies
├── parser/     — lexer + parser + AST
└── repl        — interactive loop

Teaching use

Ideal for a first PLT / logic course: students can see why (\x. y) Ω terminates under normal order but diverges under applicative order — live in the REPL.

Online version

The web REPL at tools/lambda-repl/ reuses the same ideas in vanilla JS for zero-install demos.
