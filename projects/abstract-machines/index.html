# abstract-machines

abstract-machines lambda-calculus operational-semantics

Implementations of abstract machines for the lambda calculus.

Abstract machines make evaluation explicit as transitions over a well-defined state (term, environment, stack, dump, etc.). This repository collects several classic machines and their variants — a concrete way to study how evaluators work under the hood.

GitHub →

Scope

  • ›Classic machines for call-by-name / call-by-value.
  • ›Environment and closure handling made explicit.
  • ›Companion to evaluators-exploring — same calculi, different implementation view.
